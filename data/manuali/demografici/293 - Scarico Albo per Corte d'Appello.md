# Scarico Albo per Corte d'Appello

La funzione permette l'estrazione delle variazioni di iscrizione o cancellazione dall'albo dei presidenti di Seggio, scegliendo il seguente percorso:

**Servizi Demografici ⇒ Elettorale ⇒ Albi ⇒ Albo Presidente di Seggio ⇒ Manutenzione ⇒ Scarico albo per Corte d'Appello**

[Schermata: percorso di navigazione nel menu del software PALCI - Servizi Demografici > Elettorale > Albi > Albo Presidente di Seggio > Manutenzione > Scarico Albo per Corte d'Appello]

## Opzioni di estrazione

### Estrazione file .txt

È possibile scegliere nel campo **"Corte d'appello"** la voce: **Corte d'Appello ☑** e le varie causali di cancellazione, iscrizione e le varie tipologie di estrazioni. Per estrarre un file `.txt`.

[Schermata: finestra "Scarico Albo Presidenti di Seggio" con campo "Corte d'appello" impostato su "Corte d'Appello", campo "Tipo operazione" con menu a tendina aperto che mostra le causali (Cancellazione per perdita diritto di voto, Cancellazione per incompatibilità professionale, Cancellazione per perdita di cittadinanza, Cancellazione su domanda, Cambio di residenza, Cancellazione per limiti di età, Cancellazione per migrazione, Cancellazione per migrazione AIRE, Cancellazione per decesso, Cancellazione per irreperibilità, Inserimento) e pulsante "Scarica" evidenziato]

### Estrazione file Excel

Oppure, selezionando nel campo **"Corte d'appello"** la voce: **Corte d'Appello Prefettura Modena ☑** e le varie causali di cancellazione, iscrizione e le varie tipologie di estrazioni, è possibile scaricare il file Excel.

[Schermata: finestra "Scarico Albo Presidenti di Seggio" con campo "Corte d'appello" impostato su "Corte d'Appello Prefettura Modena", campo "Tipo operazione" con menu a tendina aperto che mostra le causali (Inserimento, Aggiornamento, Cancellazione per perdita diritto di voto, Cancellazione per incompatibilità professionale, Cancellazione per perdita di cittadinanza, Cancellazione su domanda, Cambio di residenza, Cancellazione per limiti di età, Cancellazione per migrazione, Cancellazione per migrazione AIRE, Cancellazione per decesso, Cancellazione per irreperibilità) e pulsante "Scarica" evidenziato]

## Tipologie di estrazione

Sono disponibili le seguenti tipologie di estrazione:

- **"Tutti i Presidenti attivi nell'albo"**
- **"Solo iscritti in data:///"**
- **"Tutti i Presidenti attivi, escluso quelli in data:///"**
- **"Cancellati In data:///"** selezionando la **"Causale"** cliccando sulla lente 🔍

[Schermata: pannello "Estrai" con le quattro opzioni di estrazione: checkbox "Tutti i Presidenti attivi nell'albo", checkbox "Solo iscritti in data" con campo data, checkbox "Tutti i Presidenti attivi, escluso quelli iscritti in data" con campo data, checkbox "Cancellati In data" con campo data e campo "Causale" con icona lente di ricerca]

[Schermata: finestra "Tabella Causali Elettorali" con colonne ID, Descrizione e Tipologia, contenente le causali: Acquisto cittadinanza italiana (Iscrizione), Acquisto cittadinanza italiana (Iscrizione), Carta di azione (Variazione), DC Conv + Rettifica generalità (Cancellazione), Cancellazione AIRE (Cancellazione), Cancellazione AIRE - età > 100 ANNI (Cancellazione), Condanna penale (sospesa) (Cancellazione), Decisione CLEA (Cancellazione), Domanda Cancellazione - Albo (Cancellazione), Duplice iscrizione (Cancellazione), Emigrazione (Cancellazione), Emissione Provincia Autonoma (Iscrizione)]

## Download del documento

Cliccando sul tab **[Scarica]** è possibile scaricare il documento in formato `.txt` o in `.xlsx`.

> **Nota:** Nel caso di estrazione per Corte d'Appello Modena, le iscrizioni e le cancellazioni vanno estratte **insieme**.

[Schermata: anteprima del file "PreSeggio.txt" contenente i dati anagrafici dei presidenti di seggio con colonne per nome, codice fiscale, indirizzo e data di iscrizione]
