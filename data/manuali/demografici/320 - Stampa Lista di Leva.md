# Stampa Lista di Leva

Poco prima di passare alla conferma della lista di leva, e della creazione dei file TELELEVA, si procede con la stampa della lista di leva.

## Percorso di navigazione

**Servizi Demografici ⇒ Leva Militare ⇒ Conferma Lista di Leva ⇒ Stampa Lista di Leva**

[Schermata del menu di navigazione: Servizi Demografici → Leva Militare → Conferma Lista di Leva → Stampa Lista di Leva]

## Compilazione dei campi

Entrando all'interno, il programma si presenterà con una schermata contenente i seguenti campi da compilare:

- **Anno di competenza**: l'anno di riferimento per la lista di leva (es. 2008)
- **Causale di Iscrizione**: per capire quali sono le causali da indicare si può andare a consultare la tabella **Gestione Iscritti**, dove sono riportati tutti i soggetti estratti con le relative causali di iscrizione (es. `200` → Immigrazione)
- **Codice testo**: il testo da utilizzare è il seguente: `cwd_ListadiLevamodA4`
- **Ordine**: campo a tendina per selezionare l'ordinamento (es. Data di nascita)

[Schermata del form "Stampa Lista di Leva" con i campi: Anno di competenza (2008), Causale di iscrizione (200 - Immigrazione), Codice testo (cwd_ListadiLevamo... / LISTA DI LEVA MOD A4), Ordine (Data di nascita)]

## Stampa

Una volta compilati i vari campi procedere con il bottone **"Stampa"**.
