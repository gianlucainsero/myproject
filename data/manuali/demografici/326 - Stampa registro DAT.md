# Stampa registro DAT

Attraverso questo programma è possibile effettuare un riepilogo di tutti i biotestamenti ricevuti nel periodo di tempo indicato.

## Percorso di navigazione

Il percorso da seguire è:

**Servizi demografici ⇒ Stato civile ⇒ Altre operazioni ⇒ DAT biotestamento ⇒ Stampa registro DAT**

[Schermata: menu a cascata del software che evidenzia il percorso Servizi demografici → Stato civile → Altre operazioni → DAT (Biotestamento) → Stampa registro DAT]

## Compilazione dei parametri

Entrando, per poter effettuare il riepilogo, bisogna indicare il **periodo di tempo interessato**.

Inoltre è possibile effettuare la stampa anche per:

- **Nominativo** del dichiarante
- **Stato dichiarazione**:
  - 1 - Attiva
  - 2 - Revocata
  - 3 - Annullata
- **Stampa dichiarazione**:
  - Tutti
  - Mio Comune
  - Altri Comuni

[Schermata: form "Stampa Registro DAT" con i campi: Nominativo dichiarante, Data protocollo da/a, Stato dichiarazione (menu a tendina con opzioni Attiva/Revocata/Annullata), Stampa dichiarazioni (menu a tendina con opzioni Tutti/Mio Comune/Altri Comuni), pulsante "Esporta Excel"]

## Esportazione

Compilati i vari campi, in base al riepilogo che si vuole effettuare, procedere tramite il testo **"Esporta Excel"**.

Verrà generato un file Excel.

[Schermata: file Excel generato contenente le colonne: Id, Cognome, Nome, Data di nascita, Sesso, Data protocollo, Numero protocollo, Comune di registrazione, Stato dichiarazione, Data revoca]
