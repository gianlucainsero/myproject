# Allegato Verbale Graduatoria Scrutatori

Permette la redazione dell'allegato al Verbale contenente la graduatoria degli scrutatori in sostituzione a quelli impediti secondo le disposizioni dell'art.6 della L. n.95 dell'08/03/1989.

Si ricorda che è possibile selezionare il tipo di ordinamento dei sostituti: se **alfabetico** o **per numero di graduatoria**.

## Generazione del file

Per generare il file è necessario cliccare su **Stampa** a destra della videata. Di seguito si apre una videata di visualizzazione del documento con il quale è possibile interagire qualora si scelga il formato **DOCX**, da noi consigliato.

## Videata di configurazione

[Schermata della videata "Allegato Verbale Graduatoria Scrutatori" con i seguenti campi di configurazione]

| Campo | Descrizione / Valore |
|-------|---------------------|
| **Codice testo** * | Campo di ricerca (es. "Fondo anagrafe generico") |
| **Tipo Output** | Documento in formato DOCX (menu a tendina) |
| **Cod. elezione** | Campo di ricerca con icona lente |
| **Data Elezione** | Campo data |
| **Numero dal** | Campo numerico (es. 0 al 99999) |
| **Data e Nr. Verbale** | Campo di ricerca con icona lente |
| **Tipo ordinamento** | Per numero graduatoria (menu a tendina) |

> **Nota:** Il campo "Tipo ordinamento" consente di scegliere tra ordinamento **alfabetico** e **per numero di graduatoria** dei sostituti.
