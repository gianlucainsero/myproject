# Estrazione Soggetti per TELELEVA

Questa funzione permette di generare il file TELELEVA, in un formato `.txt`, da inviare al distretto militare.

## Percorso di navigazione

Il percorso da seguire è il seguente:

**Servizi Demografici** ⇒ **Leva Militare** ⇒ **Conferma Lista di Leva** ⇒ **Estrazione Soggetti per TELELEVA**

[Schermata del menu ad albero dell'applicazione: dal menu "Applicazioni" si seleziona "150. Servizi Demografici" → "40. Leva Militare" → "20. Conferma Lista di leva" → "30. Estrazione soggetti per Teleleva"]

## Compilazione dei campi

Entrando all'interno, i campi da compilare sono:

- **Anno di Competenza**;
- **Flag "Solo Attivi"** ⇒ *Che di default troverete già flaggato*;
- **Nominativo Referente**.

[Schermata del form "Estrazione soggetti per Teleleva" con i campi: "Anno di competenza" (es. 2008), "Solo attivi" (checkbox flaggata), "Nominativo referente" (campo di testo vuoto)]

## Conferma e generazione del file

Una volta compilati tutti i campi, premere sulla destra il bottone **"Conferma"**.

L'operazione si concluderà con la creazione di un file `.txt`, come riportato da immagine.

[Schermata del file generato: "TeleLeva20250218145306.txt" – 12,5 kB – Fine]
