# Importazione File 3D XML

## Percorso di accesso

Il percorso da seguire è:

**Servizi demografici ⇒ Elettorale ⇒ Manutenzione ⇒ 3D XML e Certificati penali ⇒ Importazione file 3D XML**

[Schermata di navigazione del menu: Servizi demografici → Elettorale → Manutenzione → 3D XML e Certificati penali → Importazione file 3D XML]

## Descrizione della funzione

Questa voce viene utilizzata per importare tutti i file 3D XML che il comune riceve.

L'importazione di questi file, durante la **Seconda Tornata** (dove vengono effettuate le iscrizioni), è **FONDAMENTALE** per poter effettuare l'iscrizione di quei soggetti che sono stati cancellati dal corpo elettorale di altri comuni (durante la **Prima Tornata**, dove si effettuano le cancellazioni).

> **N.B.** *Qualora il comune non avesse ricevuto il 3D, ma è stata accertata la cancellazione del soggetto, sarà piena responsabilità dell'ufficiale elettorale iscrivere il soggetto.*

## Schermata di importazione

Aprendo la funzione, comparirà la schermata di ricezione 3D XML.

[Schermata "Ricezione 3D XML" con pulsante "Carica" e sezione "Ricerca Files Protocollo" con opzione "Allega da Protocollo"]

Con questo programma è possibile effettuare un'importazione **singola** oppure **multipla**.

## Procedura di caricamento

Cliccando su **"CARICA"**, verrà fuori una schermata dove sarà possibile caricare:

- **UN SOLO FILE 3D XML** → importazione singola
- **UNA CARTELLA ZIPPATA** con all'interno tutti i file 3D XML che il comune ha ricevuto → importazione multipla

[Schermata di caricamento file: campo "Acquisizione File..." con istruzioni "Caricare un file formato .xml oppure .zip" e "Scegli un file da caricare..."]

### Note operative

- Selezionare un file 3D XML da caricare oppure l'archivio `.zip` di una cartella di file 3D XML.
- I file già precedentemente caricati non saranno rielaborati.
- È possibile premere **Ricerca files protocollati** per recuperarli dal protocollo.
