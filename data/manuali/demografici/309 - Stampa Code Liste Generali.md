# Stampa Code Liste Generali

Attraverso tale funzione è possibile effettuare la ri-stampa delle code delle liste generali relative ad una revisione elettorale.

## Percorso di navigazione

**Servizi Demografici ⇒ Elettorale ⇒ Revisioni Storiche ⇒ Stampa Code Liste Generali**

[Schermata del menu a cascata: Servizi Demografici → 20. Elettorale → 80. Revisione Storica → 50. Stampa Code Liste Generali]

## Campi da valorizzare

Entrando all'interno, i campi da valorizzare saranno i seguenti:

1. **Tipo Lista Elettorale**
2. **Verbale** → Il campo del verbale deve essere **SEMPRE** valorizzato in quanto senza non verrà effettuata alcuna stampa;
3. **Sesso**

## Procedura di stampa

Una volta compilati i campi, e controllato la correttezza del timbro finale, premere il bottone **"Conferma"** sulla destra così da procedere alla stampa.

[Schermata del form "Stampa Liste Generali" con i seguenti campi: Verbale (84), data (13/03/2025), numero (86), Sesso (Maschio), Tipo lista (Liste Elettorali), Num. lista generale da (0 a 999999).
