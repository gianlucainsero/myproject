# Stampa statistiche e creazione file modelli mensili: D.7.A e SC.6-12 sd/SDSU

Questo programma del gruppo funzioni di Stato Civile è stato aggiornato in modo da ottemperare alla normativa vigente ed è disponibile all'uso, sia nella creazione di stampe di controllo che nei file da poi inviare.

Questa guida vi mostrerà come inserire i dati e di seguito a fine di ogni mese generare il modello statistico.

---

## 1) Inserimento dati

L'inserimento dati avviene utilizzando il programma **Interrogazione indici atti**.

### Percorso di accesso

[Immagine: Menu a cascata del software con percorso: Servizi Demografici → Stato Civile → Interrogazioni → 10. Interrogazione Indice Atti]

### Videata di ricerca

Di seguito vi si aprirà una videata di ricerca, nella quale andrete a cercare i divorzi/separazioni che avete registrato durante il mese o appena redatto l'atto di stato civile, compilare come di seguito:

[Immagine: Videata "Interrogazione Indice Atti" con campi: Cognome, Nome, Anno nascita, Ricerca per matricola (facoltativa), Tipo atto (es. Matrimonio), Anno Atto (es. 2024), Numero Atto, Parte Atto, Serie Atto, Volume Atto, Delegazione Atto, A partire da Iscrizione/Trascrizione, Progressivo indice]

### Conferma e visualizzazione elenco

Confermate con **elenca (F4)** a destra della videata.

[Immagine: Pulsante "F4 - Elenca"]

Per ottenere l'elenco degli atti di matrimonio/divorzio/separazione dal quale, selezionando quelli desiderati, potrete andare a inserire i dati necessari alla redazione del modello statistico:

[Immagine: Elenco atti con colonne: Prog, Cognome, Nome, Data Nascita, Luogo Nascita, Sesso, Tipo, Anno, Data Atto, Tipo di Atto, Atto parte, Annotazione, Atto, Data consegna. A destra pulsanti: Aggiungi, Stacca/Attacca, Controllazioni, Esportazione, Elenco Atti Atti, Atti/Pratica Dettaglio, Cella Certificata, Mod.SDSU]

### Inserimento dati modello SDSU

Aprendo l'elenco prendiamo a titolo di esempio Gianluca e Chiara, selezionando uno dei soggetti e poi cliccando in basso a destra su **Mod.SDSU** ci si aprirà una videata dove inserire i dati richiesti:

[Immagine: Videata "Procedimento del rito/ricorso tipo" con campi: Progressivo, Tipo di procedimento, Data di deposito del ricorso, Data di pubblicazione, Data del provvedimento, Tipo di provvedimento emesso, Tipo separazione che ha preceduto il divorzio, Data della separazione, Rito del matrimonio. A destra pulsanti: Aggiorna, Elimina, Modifica]

I campi da inserire sono **obbligatori**, l'omissione non permette l'aggiornamento e quindi la registrazione dei dati con il pulsante **Aggiorna**.

Sono modificabili anche in un secondo momento con il pulsante **Modifica**.

> **IMPORTANTE:** una volta inseriti i dati su un soggetto, mettiamo ad esempio Chiara, questi saranno anche registrati nella medesima schermata di Gianluca. Lo stesso vale per le modifiche.

## 2) Procedere alla creazione del file

### Accesso al programma

Può essere fatto seguendo il percorso:

**Servizi Demografici → Stato Civile → Altre operazioni → Statistiche → Creazione file statistiche mensili (150/30/50-60/30)**

oppure ricercate "creazione file statistiche mensili" nella barra di ricerca.

[Immagine: Menu a cascata con percorso: Servizi Demografici → Stato Civile → 50. Altre operazioni → 50. Statistiche → 03. Creazione file statistiche mensili]

### Parametri di configurazione

Una volta effettuato l'accesso al programma vi si presenterà una schermata nella quale dovrete indicare:

- **Periodo di riferimento:** sono i campi **ANNO** e **MESE**, sono obbligatori *(evidenziati in rosso)*
- **Il tipo di modello** che desiderate produrre *(evidenziato in verde)*
- **Il tipo di elaborazione:** se una stampa di controllo, quindi un elenco che potete usare per confrontare i dati, o la creazione diretta del file da inviare. Attenzione: il file non genera i dati che non inserite, quindi controllate di aver compilato i campi necessari alle rilevazioni statistiche dell'ISTAT. *(evidenziato in azzurro)*

[Immagine: Videata "Creazione file per modelli mensili" con sezione "Selezione" (Anno: 2024, Mese: 0), sezione "Stato Civile - Modelli Istat" con checkbox: SC.6-12sd/SDSU, D.7.A, D.4 Maschi, D. 4 bis Maschi, D.4 Femmine, D. 4bis Femmine, D. 3, D. 3 U, e sezione "Tipo Elaborazione" con opzioni: Stampa di Controllo, Creazione File]

### Esempio di creazione file

Selezioniamo a titolo esemplificativo **Anno=2024** e **mese=1**, prendiamo il modello **SC.6-12 sd/SDSU** e poi lanciamo la creazione file:

[Immagine: Videata con Anno: 2024, Mese: 1, modello SC.6-12sd/SDSU selezionato, Tipo Elaborazione: Creazione File spuntato]

Cliccando su **OK** viene scaricato il modello Excel.

[Immagine: Pulsante OK]

Segnalandovi l'avvenuta creazione e la cartella nella quale viene scaricato.

[Immagine: Notifica "Creazione file per modelli mensili - Attenzione: il file SC612SD202401.csv verrà scaricato nella cartella Download" e cronologia dei download con file "SC612SD202401.csv"]

Lo stesso nel caso del modello **D.7.A** o altri modelli.
