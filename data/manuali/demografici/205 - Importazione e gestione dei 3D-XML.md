# Importazione e gestione dei 3D-XML

## Importazione 3D-XML

È possibile caricare un singolo file XML o un intero archivio dal menù:

**Servizi demografici → Elettorale → Elettorale → 3D XML → Importazione file 3D XML**

Sono presenti due modalità per importare i 3D-XML:

- importazione massiva tramite file `.zip` contenente tutti i 3D-XML
- importazione singola tramite il protocollo Palitalsoft

Se sono stati archiviati tutti i 3D XML all'interno di una cartella di sistema occorre generare un file `.zip`. Dopo di che premendo **Carica** è possibile selezionare tale file e caricare l'intero archivio.

Inoltre è possibile selezionare i 3D XML scegliendoli direttamente dal protocollo Palitalsoft premendo il pulsante **Allega da protocollo**.

[Interfaccia di importazione 3D-XML: campo di selezione file con pulsanti "Carica" e "Allega da Protocollo". Il campo accetta file in formato `.xml` oppure `.zip`. È presente anche un pulsante "Ricerca files Protocollo" per recuperare file dal protocollo.]
