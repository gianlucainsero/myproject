# Prospetto situazione elettori

Dal menù **Servizi demografici** → **Elettorale** → **Elettorale** → **Statistiche Elettorali** → **Prospetto situazione elettori** è possibile generare un prospetto di tutte le liste elettorali con elettori attivi contenente il numero degli elettori maschi e femmine suddiviso per sezione alla **data odierna**.

Premere **Stampa** per generare il file.
