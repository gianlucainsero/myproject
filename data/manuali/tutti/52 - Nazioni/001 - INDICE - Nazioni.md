# Nazioni

**Punto di menù:** Servizi Demografici → Modulo Base → Tabelle Generali → Stati e Paesi → Nazioni

## Ricerca

La schermata iniziale appare con una finestra di ricerca, dove è possibile ricercare per descrizione, id o gruppo. Con il tasto **Elenca** possiamo vedere tutte le nazioni inserite.

[Schermata di ricerca Nazioni: campo Descrizione, campo Id, campo Gruppo con pulsante di ricerca a lente d'ingrandimento. A destra pulsanti: Nuovo, Elenca (evidenziato), Cancella, Salva, Reset. In basso a destra: Formato Ricerca.]

## Creare una Nuova Nazione

Per creare una Nuova Nazione: → **Nuovo**

[Schermata elenco Nazionalità: tabella con colonne Id, Descrizione, Sigla, Gruppo, Cittadinanza, ISO_3166 (A2), Data Inizio, Data Fine, Utente, Data. Esempi di righe: 1 ITALIA, 201 ALBANIA, 202 ANDORRA, 203 AUSTRIA, 206 BELGIO, 209 BULGARIA, 212 DANIMARCA, 214 FINLANDIA, 216 FRANCIA. A destra pulsanti: Nuovo (evidenziato), Altra Ricerca.]
