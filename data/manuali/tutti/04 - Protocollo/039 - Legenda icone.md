# Legenda icone

## Icone sulle tabelle

| Icona | Descrizione |
|-------|-------------|
| ✏️ | Modificare la riga selezionata |
| 🖨️ | Stampare la tabella in formato PDF |
| 📊 | Stampare la tabella in formato Excel |
| 🗑️ | Cancellare la riga selezionata della tabella |
| 🔄 | Aggiornare la tabella (Refresh) |
| ➕ | Aggiungere un elemento alla tabella |
| ⚙️ | Personalizzare la larghezza delle colonne della tabella |

## Icone sui portlet

| Icona | Descrizione |
|-------|-------------|
| ✉️ (grigia) | Il protocollo è in sola visione e non è stato aperto |
| ✉️ (aperta) | Il protocollo è in sola visione ed è stato aperto |
| 📩 (verde) | Il protocollo è in gestione e non è ancora stato aperto |
| 📩 (verde, aperta) | Il protocollo è in gestione, è stato aperto, ma non ancora preso in carico |
| 📩 (verde, pieno) | Il protocollo è in gestione, è stato aperto e preso in carico |
| 👥 | Il protocollo è stato trasmesso a tutto l'ufficio |
| 🚫 | Il protocollo è stato rifiutato da un assegnatario |
| ❗ | Il protocollo non è stato fascicolato |
| 👤 | Indica da chi è stato creato il protocollo |
| 📄 | Simbolo del Protocollo |
| 📄 (verde) | Simbolo del Documento alla firma |
| P | Il tipo di protocollo: **A** (arrivo), **P** (partenza), **C** (interno formale), **I** (documento alla firma) |
| 🔴 | Il protocollo è da firmare |
| 💶 | Il protocollo è una fattura elettronica |
| 📧 (colonna "Oggetto") | Arrivo protocollato da PEC |
| 📧 (colonna "Notifica") | Mail inviata correttamente |
| 📧 ✔ ✔ | PEC inviata e ricevute di accettazione e avvenuta-consegna associate correttamente |
| 📧 ✔ ✔ (parziali) | Le ricevute di accettazione e consegna non sono presenti per tutti i destinatari (in caso di invio misto PEC + mail), ma **non risultano anomalie** di invio |
| ⚠️ | Anomalia circa la mancata accettazione/consegna della PEC |
| 📎 | Presenza di allegati |
| ⚠️ (allegati) | Mancanza di allegati |
| 👤 (rosso) | Protocollo non assegnato |
| 🔒 | Protocollo a cui è stata indicata una data di scadenza entro la quale gestirlo |
| ✅ | Protocollo già visionato/gestito e chiuso |
| 📤 | Protocollo ritrasmesso |

## Icone in Trasmissioni del Documento

| Icona | Descrizione |
|-------|-------------|
| ✔️ (grigio) | L'utente che ha trasmesso il protocollo |
| ✅ (verde) | Il protocollo è ancora aperto tra i Protocolli in carico dell'assegnatario |
| ✅ (rosso) | Il protocollo è solamente in visione oppure, se era stato assegnato in gestione, è stato lavorato e chiuso dall'assegnatario |
| 🚫 | Il protocollo è stato rifiutato dall'assegnatario |

## Colori nei portlet

| Colore | Significato |
|--------|-------------|
| 🟡 Giallo | Mancanza di allegati |
| 🟠 Arancione | Mancanza di assegnatari |
| ⬛ Nero | Protocollo annullato |
| ⬜ Grigio | Protocollo riservato |

> **Esempio visivo dei colori nei portlet:**
>
> [Giallo] `P | 2018 | 423 | 16/10/2018 | ITALSOFT` → mancanza di allegati
>
> [Arancione] `A | 2018 | 414 | 11/10/2018 | ITALSOFT` → mancanza di assegnatari
>
> [Nero] `C | 2018 | 43 | 05/09/2018 | MUCCI ALESSANDRO` → protocollo annullato
>
> [Grigio] `P | 2018 | 406 | 05/10/2018 | RISERVATO | RISERVATO` → protocollo riservato
