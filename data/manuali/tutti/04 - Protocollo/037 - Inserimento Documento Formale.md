# Inserimento Documento Formale

I documenti formali servono per inviare comunicazioni interne. Protocollare un documento formale è molto simile a protocollare una partenza.

Dato che il documento formale è per usi interni **non è necessario inserire i destinatari esterni**.

Per tutte le funzionalità si fa riferimento alla protocollazione in Partenza. (Vedi: *Guida alla Protocollazione in Partenza*)

## Interfaccia di gestione

[Schermata: Interfaccia "Gestione Documenti Formali" con i seguenti campi e sezioni:]

### Dati di intestazione

| Campo | Descrizione |
|-------|-------------|
| **Segnatura** | Segnatura del documento |
| **Doc. Formale** | Numero del documento formale |
| **Data** | Data del documento (es. 17/12/2014) |
| **Ora** | Ora di protocollazione |
| **Ultima modifica** | Data e ora dell'ultima modifica |
| **Utente** | Utente che ha protocollato (es. `michele`) |
| **Tipo** | Tipo di protocollo (es. `PROTOCOLLO`) |

### Dati Principali

| Campo | Descrizione |
|-------|-------------|
| **Prot. Collegato** | Numero di protocollo collegato (es. `046321`) |
| **Anno** | Anno del protocollo collegato (es. `2014`) |
| **Tipo** | Tipo del documento collegato (es. `A`) |
| **Oggetto** | Oggetto del documento (es. "sagra della porchetta") |
| **Mitt/Firmatario** | Mittente/Firmatario (es. "Asp Paolo Ricci") |
| **Mittenti Aggiuntivi** | Pulsante per aggiungere mittenti aggiuntivi |
| **Titolario** | Codice titolario (es. `0008`) |
| **Anno/Fascicolo** | Anno e fascicolo (es. `0004`) |
| **Commercio** | Categoria (es. "Commercio") |

### Commercio Interno

| Campo | Descrizione |
|-------|-------------|
| **Ufficio** | Ufficio di destinazione |
| **Settore** | Settore di destinazione |
| **Destinatario** | Destinatario interno |

### Tabella DESTINATARI

| Descrizione | Gest. | Resp. | Originale | Termine | Mail | Acc. | Cons. |
|-------------|-------|-------|-----------|---------|------|------|-------|

## Azioni disponibili (pulsanti a destra)

- **F2 - Nuovo**: Crea un nuovo documento formale
- **F5 - Registra**: Registra il documento
- **Duplica Doc.**: Duplica un documento esistente
- **Metti in Riservato**: Imposta il documento come riservato
- **Vai Partenza**: Accede alla protocollazione in Partenza
