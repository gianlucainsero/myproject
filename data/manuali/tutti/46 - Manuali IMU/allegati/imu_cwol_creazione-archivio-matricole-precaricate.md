# Caricamento Matricole Precaricate

## Da foglio XLS o XLSX

È possibile caricare un archivio di matricole da foglio XLS e/o XLSX.

**Requisito:** all'interno del foglio deve essere presente la colonna `PROGSOGG`.

### Procedura di importazione

1. Navigare nel menu: **70. Tributi → 140. Modulo Base → 70. Utilità → 20. Archivio Precompilato**

   [Screenshot: percorso di navigazione nel menu ad albero del software CityWare]

2. Si aprirà l'elenco degli archivi già creati. Andare sul pulsante a destra **"Importa Excel"**.

   [Screenshot: elenco archivi matricole precaricate con pulsante "Importa Excel" evidenziato]

3. Scegliere il file da caricare.

4. Scrivere il nome dello **sheet** (es. `Foglio1`).

   [Screenshot: finestra "Importa Excel" con campi per selezione file, riga intestazione, nome sheet e nome archivio]

   Esempio di struttura del foglio Excel:

   | A (progsogg) | B | C | D | E |
   |---|---|---|---|---|
   | 20209 | | | | |
   | 15737 | | | | |
   | 24278 | | | | |
   | 3868 | | | | |

5. Scrivere il nome dell'archivio e premere il tasto **"+ Aggiungi"**.

6. È possibile caricare più fogli di Excel, creando più archivi precompilati, ripetendo l'operazione.

7. Dopo aver completato le operazioni, premere il tasto **"Importa"**.

   [Screenshot: finestra "Importa Excel" con archivio caricato e pulsante "Importa" evidenziato]

## Inserimento Nuovo Archivio

Sempre dall'elenco degli archivi già presenti, fare **"Nuovo"**.

[Screenshot: elenco archivi matricole precaricate con pulsante "Nuovo" evidenziato]

1. Inserire nel campo **"Descrizione"** il nome che si vuole dare al nuovo archivio e andare sul pulsante **"Aggiungi"**.

   [Screenshot: campo Descrizione con valore "Prova archivio matricole bonificate" e pulsante "Aggiungi"]

2. Appare il messaggio di conferma:

   > **Record inserito correttamente**

3. Andando su **"Altra Ricerca"** e poi **"Elenca"** si può visualizzare l'archivio appena creato (testata).

   [Screenshot: elenco archivi con il nuovo archivio "Prova archivio matricole bonificate" evidenziato]

4. Posizionandosi sulla riga del nuovo archivio e andando sul pulsante a destra **"Matricole"**.

   [Screenshot: elenco archivi con pulsante "Matricole" evidenziato]

5. Appare il seguente messaggio in quanto l'archivio ancora è vuoto:

   > ⚠ **Nessun record trovato.**

   [Screenshot: finestra "Matricole" vuota con messaggio "Nessun record trovato"]

## Inserimento di una nuova matricola

Chiudendo la finestra con la crocetta ci si trova nella seguente videata; facendo **"Nuovo"** o andando sul **"+"**, si può inserire una nuova matricola.

[Screenshot: finestra "Matricole" con pulsante "Nuovo" e pulsante "+" evidenziati]

1. Scrivere negli appositi campi di ricerca la **matricola** da inserire oppure il **nominativo** del soggetto.

   [Screenshot: finestra di ricerca soggetto con campi "Nominativo", "Matricola" e "Cod.Fisc./P.IVA"]

2. Comparirà il pulsante **"Aggiungi"** che permette di aggiungere il soggetto richiamato.

   [Screenshot: soggetto trovato con dati anagrafici e pulsante "Aggiungi" evidenziato]

3. Per **cancellare** il soggetto inserito, posizionarsi sulla riga e andare sul pulsante **cancella** (icona cestino) in basso.

   [Screenshot: elenco matricole con il soggetto inserito e pulsante cancella evidenziato nella barra in basso]
