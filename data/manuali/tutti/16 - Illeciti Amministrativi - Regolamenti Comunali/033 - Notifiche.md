# Notifiche

## Percorso di accesso

Dai **tre puntini**:

▶ **Illeciti Amministrativi / Regolamenti Comunali** ▶ **Verbali** ▶ **Notifiche**

## Notifiche per Verbale

Si presenta inizialmente con un form di ricerca identico a quello raffigurato nel sottocapitolo precedente. La ricerca specifica per un verbale porterà al dettaglio del tale. In questa schermata, sarà possibile inserire la notifica facendo click sul bottone **Nuovo**, presente sulla destra della schermata.

## Pop-up di inserimento Notifica

Il pop-up di inserimento che comparirà sarà il seguente:

[Immagine: Finestra di dialogo "Notifica" con i seguenti campi di inserimento:]

| Campo | Descrizione / Valore di esempio |
|-------|-------------------------------|
| **Tipo Notifica** | REGOLARE (campo a ricerca con icona X per cancellare) |
| **Not.** | Campo numerico con simbolo $ |
| **Spese** | Campo numerico (es. 0,00) |
| **Soggetto** | Campo a ricerca (icona lente) |
| **Data** | Campo data nel formato `__/__/____` (icona calendario) |
| **Note** | Campo di testo libero |
| **Scatola** | Campo di testo |
| **Busta** | Campo di testo |
| **Prog.** | Campo di testo |
| **Numero Documento** | Campo di testo |
| **Immagine** | Campo con icone di ricerca, allegato e cancellazione |
| **Data Inserimento** | Campo data (es. 09/11/2021) con icona calendario |

In basso a sinistra è presente il pulsante **Salva** per confermare l'inserimento della notifica.
