# Inserimento da Dispositivi ▶ TRACCIATI GENERICI

Per caricare un servizio che **non** proviene da Dispositivi (ovvero Autovelox, Varchi, Semafori/FTR), come da File Scansionati, Foto, Lettura Tracciati di interscambio con altri Software predisposti, Lettura Preavvisi Ausiliari generati da dispositivi palmare, ecc, … Possiamo usare questa procedura (Ad esempio, possiamo inserire gli iter massivamente).

Per farlo ci prepariamo una cartella zip con dentro i file interessati.

## Percorso di accesso

Dai **tre puntini** seguire il percorso:

> ▶ **Codice della Strada** ▶ **Inserimento da Dispositivi** ▶ **Tracciati Generici**

[Diagramma: Menu a cascata con percorso: 30. Polizia Locale → 10. Codice della Strada → 10. Inserimenti da Dispositivi → 40. Tracciati Generici]

> **ATTENZIONE\*!:** Se sono stati importati altri file non si sovrapporranno a quelli che si vuole importare ora in automatico, ma bisogna cliccare sul pulsante **'Vuota'**.

Per prima cosa vedremo l'elenco degli ultimi servizi precedentemente inseriti da un operatore autorizzato.

Sempre da questa schermata iniziale potremmo caricare un nuovo tracciato/file scansionati per procedere all'operazione massiva.

## Caricamento dei file

Preparata la cartella zippata con dentro i file interessati, fare **[Upload]** per caricare la cartella.

[Diagramma: Schermata "Caricamento file" con finestra di selezione file di Windows, pulsante Upload evidenziato in rosso, cartella compressa "TEST" selezionata]

Caricata la cartella, **ogni elemento avrà una sua riga**. A questo punto sarà necessario verificare l'esattezza delle informazioni al suo interno e, se mancanti, inserire le informazioni base (come, ad esempio, il numero di targa ed il modello del veicolo fotografato).

[Diagramma: Elenco dei file caricati con colonne: Prog, Flag, Err, Op, Data Accertamento, Data Infrazione, Ora, Luogo Infrazione, Targa, Nasc, Tipo, Serie, Flag, Foto, Cont, Cod. Strade, Cod. Preavv, Articolo, Somma, Somma Max, Somma Min, Oggetto, Verbale, Anno. In basso la tabellina "Note" con segnalazioni di errori]

Eventuali segnalazioni da verificare saranno riepilogati nella sezione sottostante all'elenco dei file caricati, la tabellina denominata **'Note'**.

## Correzione dei dati e scarico

Per poter sistemare questi dati occorre entrare nel dettaglio di quel file con un **doppio click**. Una volta che non ci saranno più Segnalazioni in 'Note' da esaminare, si potrà provare a fare lo scarico col bottone **[Scarica]**, il quale verbalizzerà tutti i fotogrammi corretti (quindi senza errori/anomalie o mancanze).

[Diagramma: Tabella "Note" con elenco di errori tipo: DATA INFRAZIONE NON VALIDA, Record di dettaglio numero 1 LUOGO INFRAZIONE MANCANTE, Record di dettaglio numero 1 CODICE VIGILE MANCANTE, Record di dettaglio numero 1 NOME VIGILE NON VALIDO, Record di dettaglio numero 1 TARGA NON VALIDA, Record di dettaglio numero 1 SOMMA NON CORRETTA: 0, ecc.]

[Diagramma: Pulsanti "Vuota" e "Scarica" a destra dello schermo, con finestra di conferma "Confermi l'elaborazione del file importato?" con pulsanti Conferma/Annulla]

## RIEPILOGO DEI COMANDI e FUNZIONI

Legenda riepilogativa dei comandi e le loro rispettive funzioni:

- **[Leggi]** se il vostro dispositivo prevede la lettura configurata da una cartella FTP
- **[Upload]**, posto in alto alla schermata permetterà di caricare manualmente una cartella zip dal vostro desktop

A destra dello schermo abbiamo:

- **[Vuota]** per cancellare definitivamente una lista importata (Nota: Se sono stati importati altri file non si sovrapporranno a quelli che si vuole importare ora in automatico)
- **[Scarica]** confermerete l'importazione
