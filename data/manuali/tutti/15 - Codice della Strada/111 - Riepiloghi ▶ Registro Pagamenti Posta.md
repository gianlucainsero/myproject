# Riepiloghi ▶ Registro Pagamenti Posta

Questa voce ha lo scopo di riepilogare tutti i pagamenti pervenuti tramite poste.

I dati sono riepilogati in una tabella ordinata per data operazione. Per questa lista è possibile filtrare i risultati attraverso i campi di testo sotto l'intestazione della tabella. È possibile stampare la lista intera o stampare soltanto i pagamenti con anomalie.

## Percorso di accesso

Dai **tre puntini** e seguendo il percorso:

> ▶ **Codice della Strada** ▶ **Riepiloghi** ▶ **Registro Pagamenti Posta**

## Schermata del Registro

Ci ritroveremo in una schermata con uno storico dei pagamenti avvenuti a mezzo del rendiconto periodico scaricato dal sito Poste Italiane, completi di tutti i relativi dettagli.

La tabella "Pagamenti Poste Storico" contiene le seguenti colonne:

| Colonna | Descrizione |
|---------|-------------|
| Nome | Nome del file/rendicontazione (es. `2023013012345_ESIMPO_CD29_1`, `rendicontazione (TLCD29_2882011`) |
| ID | Identificativo del verbale |
| Err | Indicatore di errore |
| Verbale | Numero del verbale |
| Anno | Anno del verbale |
| Tipo | Tipo di operazione (es. `P`, `V`) |
| Data Oper. | Data dell'operazione |
| Tipo Bull. | Tipo bollettino (es. `896`) |
| Importo | Importo del pagamento |
| Targa | Targa del veicolo |
| Concitatore | Figura del concitatore (es. `Proprietario`) |
| Quarto Campo | Riferimento aggiuntivo |
| Immagine Fronte | Riferimento all'immagine del bollettino (es. `20230130_1675077940531.jpg`) |

## Funzionalità di stampa

A destra dello schermo sono presenti due pulsanti:

- **[Stampa Lista]** – per creare un'anteprima di stampa dell'intera lista
- **[Stampa Pagamenti con Anomalie]** – per creare un'anteprima di stampa solo dei pagamenti con anomalie

L'anteprima si aprirà in una scheda chiamata **"Visualizzatore Documenti"** che potrà essere salvata nel proprio dispositivo attraverso il pulsante **[Scarica]**.
