# Generare e scaricare il tracciato 290 del ruolo

Apri **Visualizza Ruolo** dopo avere completato i controlli sulle posizioni.

1. Avvia il comando **Tracciato 290** e salva il file proposto dal browser.
2. Verifica che il download sia completato e che la creazione del supporto sia riportata nella scheda del ruolo. Per recuperare di nuovo il file usa **Scarica tracc.**.
3. Carica il file nel servizio dedicato all’invio del tracciato 290 sul portale dell’Agenzia delle Entrate. Il download dal gestionale prepara il file per questo passaggio.
