# Bdap

Questo programma permette di estrapolare il file XBRL da inviare alla BDAP con i dati del consolidato.

## Procedura

### 1. Apertura del programma

All'apertura verrà visualizzata la seguente pagina:

[Schermata iniziale del programma Bdap: campo "Tipo di File" (menu a tendina), campo "Codirne" (campo di testo con codice es. 316842930934404902), pulsante "Conferma" sulla destra]

### 2. Selezione del tipo di dato

Selezionato il tipo di file comparirà la tab per permettere di scegliere il tipo di dato.

[Schermata con campo "Tipo di File" popolato (es. bdap-xbrl-cons_2022-12-15), campo "Tipo di Dati" (menu a tendina con opzione "Consolidato"), campo "Codirne" (campo di testo), pulsante "Conferma" sulla destra]

### 3. Generazione del file

Premendo il tasto **Conferma** nella destra della schermata si otterrà il file `.xbrl` con i dati.
