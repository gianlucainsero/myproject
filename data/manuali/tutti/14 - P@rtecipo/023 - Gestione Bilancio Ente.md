# Gestione Bilancio Ente

Il programma permette il caricamento del bilancio dell'ente.

## Pagina Principale

La pagina principale si presenta con una tab che permette di scegliere la tipologia interessata.

[Schermata principale: campo a tendina "Tipologia" e barra dei pulsanti a destra]

Alla destra abbiamo 3 bottoni che ci permetteranno di eseguire le funzioni del programma:

1. **nuovo**
2. **importa xls**
3. **elenca** – permette di elencare i dati già inseriti

---

## Gestione Bilancio Ente (nuovo)

Questa schermata permette di aggiungere un nuovo bilancio compilando i dati richiesti. Il campo **prospetto** è obbligatorio.

[Schermata "nuovo": campi Prospetto (a tendina), Importa, Importa Anno P., Lettera, Rif 1, Rif 2, Rif 3 e pulsanti a destra]

Alla destra abbiamo 3 bottoni che ci permetteranno di eseguire le funzioni del programma:

1. **aggiungi** – per aggiungere i dati compilati
2. **importa xls**
3. **Altra ricerca** – ritorna alla pagina di ricerca

---

## Gestione Bilancio Ente (importa xls)

Il bottone farà aprire un popup che permetterà di caricare un file `.xls`.

[Popup "Acquisizione File....": campo "Caricare Un file formato .xlsx" con pulsante di selezione file "Scegli un file da caricare..."]
