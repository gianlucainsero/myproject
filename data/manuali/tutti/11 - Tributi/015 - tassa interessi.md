# Tassa Interessi

Dall'applicativo **Tassa interessi** è possibile modificare i dati della tassa interessi.

Alla sua apertura l'applicativo si presenterà come segue:

[Schermata dell'applicativo "Tassa Prov. ExEca Interessi" con la seguente struttura:

**Sezione "Tabella % Tassa Provinciale / ExEca / Interessi":**

- Tassa Provinciale: campo di input (valore di esempio: 5) %
- Ex-ECA: campo di input (valore di esempio: 0) %
- Maggiorazione: campo di input (valore di esempio: 0)
- Tar. Volumi Svuotati: campo di input (valore di esempio: 0)
- Interessi: campo di input %
- Importo Minimo applicabile (Sanzione): campo di input
- Per le % di Sanzione: campo di input — delimitate da (,)

**Sezione "% Interessi":**

| Calcolo anno | Con il tasso interesse | dell'anno | Decorrenza |
|---|---|---|---|
| 2010 | campo di input % | 2011 | campo di input |
| 2011 | campo di input % | 2012 | campo di input |
| 2012 | campo di input % | 2013 | campo di input |
| 2013 | campo di input % | 2014 | campo di input |
| 2014 | campo di input (valore: 0) % | 2015 | campo di input |

In alto a destra è presente il pulsante **F6 - Aggiorna**.]

Inseriti i dati da aggiornare basterà premere sul bottone **Aggiorna** per rendere effettive le modifiche e le visualizzazioni.
