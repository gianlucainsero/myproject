# Amministratori

## Accesso alla funzione

Si accede ad **Amministratori** attraverso il menù:

**Gestione Documentale → Archivi → Amministratori**

## Schermata principale

Dalla schermata principale è possibile:

- Creare un nuovo record tramite il pulsante **"Nuovo"** (F2)
- Impostare un filtro di ricerca
- Eseguire una ricerca tramite il pulsante **"Altra Ricerca"** (F3)
- Elencare i record tramite il pulsante **"Elenca"** (F4)

### Filtri di ricerca

I filtri di ricerca disponibili nella schermata principale sono:

- **Codice**
- **Cognome**
- **Sigla**
- **Categoria**

Impostando più filtri di ricerca contemporaneamente è possibile operare ricerche complesse.

Una volta completata l'impostazione dei filtri di ricerca, basterà cliccare su **"Elenca"** per ottenere un elenco dei record filtrati.

Cliccando sul pulsante **"Elenca"**, senza aver impostato alcun filtro, il programma proporrà tutti i record presenti nel sistema.

### Elenco record

L'elenco dei record Amministratori mostra le seguenti colonne:

| Colonna | Descrizione |
|---------|-------------|
| Codice Amministratore | Codice identificativo dell'amministratore |
| Cognome e Nome | Nome e cognome dell'amministratore |
| Categoria | Categoria di appartenenza |
| Sigla | Sigla associata |
| Codice Soggetto | Codice del soggetto collegato |

## Scheda Amministratore

La scheda di dettaglio di un amministratore contiene i seguenti campi:

- **Codice Amministratore*** (obbligatorio)
- **Codice Soggetto*** (obbligatorio)
- **Titolo**
- **Denominazione*** (obbligatorio)
- **Cod.Fiscale / Partita Iva**
- **Indirizzo**
- **Città**
- **Cap**
- **Provincia**
- **Posta Elettronica**
- **Telefono**
- **Fax**
- **Partito**
- **Categoria*** (obbligatorio)
- **Capogruppo**
- **Persona Giuridica** (checkbox)

### Pulsanti della scheda

- **F6 - Aggiorna**
- **F7 - Cancella**
- **F3 - Altra Ricerca**
- **F5 - Vedi Cariche**

## Gestione Storica delle Cariche

Tramite il pulsante **F5 - Vedi Cariche** si accede alla finestra **"Gestione Storica delle Cariche"**.

### Elenco delle cariche

La finestra mostra un elenco con le seguenti colonne:

| Colonna | Descrizione |
|---------|-------------|
| Org. | Organo di riferimento |
| Descrizione | Descrizione della carica |
| Posiz. | Posizione |
| Carica | Tipo di carica (es. CONSIGLIERE) |
| Dal Periodo | Data di inizio |
| Al Periodo | Data di fine |

### Pulsanti nella finestra Cariche

- **F2 - Nuovo**
- **F5 - Aggiungi**
- **F4 - Elenca**

### Inserimento nuova carica

Per aggiungere una nuova carica sono richiesti i seguenti campi:

- **Organo*** (obbligatorio) – campo con ricerca (icona lente)
- **Posizione*** (obbligatorio)
- **Carica*** (obbligatorio) – campo a tendina
- **Descrizione**
- **Dal Periodo*** (obbligatorio) – campo data
- **Al Periodo** – campo data
- **Da Atto: numero** / **anno**
- **A Atto: numero** / **anno**

## Archivio Soggetti/Mittenti/Destinatari

Tramite il pulsante **F5 - Aggiungi** (nella sezione Codice Soggetto) si accede alla finestra **"Archivio Soggetti/Mittenti/Destinatari"**.

### Campi della finestra

- **Codice**
- **Denominazione**
- **Annullati** (checkbox)

### Filtri di ricerca

- **Tutti** (radio button)
- **Soggetti Interni** (radio button, selezionato di default)
- **Soggetti Esterni** (radio button)

### Pulsanti

- **F2 - Nuovo**
- **F4 - Elenca**
