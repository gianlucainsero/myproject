# Rigenerare un Atto Completo

## Cos'è l'Atto Completo

Per **"Atto completo"** si intende un file in formato PDF (normalmente denominato col prefisso `ORIGINALE_COMP_PDF`) generato dal sistema di gestione degli atti e comprendente:

- il testo dell'atto
- i visti espressi per l'atto
- eventuali allegati all'atto marcati come "pubblicabili"

Tale funzione è normalmente impostata in modo da attivarsi **automaticamente alla conclusione dell'iter dell'atto**, ma può comunque essere attivata **manualmente** dall'operatore, anche ad iter ancora in corso.

## Problema: generazione manuale anticipata

Proprio la generazione manuale del file "Atto completo" può creare delle mancanze nella generazione del file stesso, come nel caso in cui tale file venga generato **prima che tutti i pareri da allegare all'atto vengano espressi**.

## Procedura di correzione

Per correggere un file "Atto completo" che risulti carente, seguire i seguenti passaggi:

1. **Sbloccare l'atto**: cliccare sulla barra di destra il tasto **"sblocca"** e inserire la propria password per completare l'operazione di sblocco.

2. **Eliminare il file errato**: cliccare sul file riportante il prefisso `ORIGINALE_COMP_PDF` per procedere alla sua eliminazione.

3. **Rigenerare il PDF**: una volta eliminato il testo completo erroneamente generato, cliccare nuovamente sulla barra di destra il tasto **"Genera PDF"** alla voce **"Componi atto PDF"** per generare una nuova versione dell'atto completo che riporti tutto quanto dovuto.

4. **Ribloccare l'atto**: una volta completata l'operazione, procedere a bloccare nuovamente l'atto.
