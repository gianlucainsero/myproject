# Progressivi Vari

Si accede a **Progressivi Vari** attraverso il menù → **Gestione Documentale** → **Parametri** → **Progressivi Vari**.

## Gestione Progressivi

La schermata principale presenta la scheda **Gestione Progressivi** con i seguenti parametri configurabili:

| Parametro | Valore di esempio | Descrizione |
|-----------|-------------------|-------------|
| Progressivo atti soggetti | 131 | Numero progressivo per gli atti soggetti |
| N. allegati atti soggetti | 0 | Numero di allegati per atti soggetti |
| N. progressivo comunic.x prefettura | 1 | Numero progressivo comunicazione per prefettura |
| N. Progressivo comunic.x capogruppo | 69 | Numero progressivo comunicazione per capogruppo |
| N. Progressivo generale determine | 1179 | Numero progressivo generale per le determine |
| Blocco delibere | Sì / No | Attiva/disattiva il blocco delibere |
| Stampa pareri su originale | Sì / No | Stampa dei pareri sull'originale |
| Utilizza campo memo | Sì / No | Utilizzo del campo memo |
| Determina su unica pagina | Sì / No | Determina su pagina unica |
| Ordinanza su unica pagina | Sì / No | Ordinanza su pagina unica |
| Utilizza Dipartimenti | Sì / No | Utilizzo dei dipartimenti |

## Parametri Ambiente

La scheda **Parametri Ambiente** consente di configurare i parametri di ambiente:

| Parametro | Valore di esempio | Descrizione |
|-----------|-------------------|-------------|
| Nuova modalita' di funzionamento | Sì / No | Attiva la nuova modalità di funzionamento |
| Archiviazione Testi Segreteria | Segreteria | Cartella di archiviazione dei testi di segreteria |
| Flag Web Interno x nuovo Doc. | MiWord | Flag per documento web interno nuovo |
| Flag Web Esterno x nuovo Doc. | — | Flag per documento web esterno nuovo |
| Tipi Mod.Riservati | AUTO.BAND.GARE.NEWS.PRIV.INFO.REGG.LIQUID. | Tipi di modelli riservati |
| Flag Web Interno dopo Public. | — | Flag web interno dopo pubblicazione |
| Flag Web Esterno dopo Public. | — | Flag web esterno dopo pubblicazione |

## Pulsanti disponibili

- **Aggiorna**: salva le modifiche apportate ai parametri.
