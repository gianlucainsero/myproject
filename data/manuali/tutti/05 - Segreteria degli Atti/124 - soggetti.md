# Soggetti/Mittenti/Destinatari

## Accesso al modulo

Si accede a **Soggetti/Mittenti/Destinatari** attraverso il menù:

→ **Gestione Documentale** → **Archivi** → **Soggetti/Mittenti/Destinatari**

## Schermata principale

Dalla schermata principale è possibile:

- Creare un nuovo record tramite il pulsante **"Nuovo"**
- Impostare un filtro di ricerca

### Ricerca dei record

- Impostando **più filtri di ricerca contemporaneamente** è possibile operare ricerche complesse.
- Una volta completata l'impostazione dei filtri di ricerca, basterà cliccare su **"Elenca"** per ottenere un elenco dei record filtrati.
- Cliccando sul pulsante **"Elenca"**, senza aver impostato alcun filtro, il programma proporrà **tutti i record** presenti nel sistema.

| Campo | Descrizione |
|-------|-------------|
| **Codice*** | Codice identificativo del soggetto (es. 010005) |

| **Telefono** | Numero di telefono |
| **Cellulare** | Numero di cellulare |

| **Codice AOO** | Codice AOO |

| **Tipo soggetto** | Menu a tendina (es. "Indefinito") |
| **Estremi di Assunzione** | Campo testo |
| **Codice Destinatario Remoto** | Campo con pulsante di ricerca |

### Pulsanti di azione (barra laterale destra)

- **F6-Aggiungi** — Salva nuovo record
- **F7-Cancella** — Elimina record
- **F3-Altra Ricerca** — Torna alla ricerca
- **F9-Torna Elenco** — Torna all'elenco dei record

## Creazione di un nuovo record

Per creare un nuovo soggetto, dalla schermata principale cliccare su **"Nuovo"** (oppure **F2**). Si apre la scheda vuota con i medesimi campi descritti sopra.

[Schermata di nuovo record: tutti i campi vuoti, campo "Codice*" obbligatorio. Pulsanti a destra: F5-Aggiungi, F3-Altra Ricerca, Progressivo.]

> **Nota:** I campi contrassegnati con asterisco (*) sono obbligatori.
