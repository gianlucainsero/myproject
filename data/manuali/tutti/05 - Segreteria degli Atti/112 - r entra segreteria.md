# Entra nell'ambiente

## Inserimento Credenziali

1. Aprire il browser predefinito per l'accesso, di solito cliccando sull'icona di Firefox o Chrome predisposta dal CED.
2. Si visualizza la pagina del primo accesso con il cursore posizionato sul campo **Nome Utente**.
3. Inserire il proprio nome utente, secondo le regole definite dal CED, e passare al campo successivo con il tasto invio o tabulazione.
4. Inserire la propria password nel campo **Password**.
5. Selezionare l'**Ente** di riferimento.
6. Cliccare il bottone **Entra** per accedere.

## Password Scaduta o Primo Accesso

1. Al primo accesso o se la password è scaduta, si visualizza la finestra di aggiornamento password.
2. Inserire la nuova password nel campo **Nuova Password** per le credenziali d'accesso, tenendo conto delle regole descritte dalla maschera di inserimento.
3. Ripetere la nuova password nel campo **Conferma Password**.
4. Cliccare il bottone **Aggiorna** per continuare.

### Regole per la nuova password

La password richiesta deve rispettare le seguenti regole:

- **Lunghezza minima:** 8 caratteri
- **Lunghezza massima:** 16 caratteri
- Può contenere soltanto i simboli: `! $ % & / ( ) = ? - _ *`
- Deve contenere sia lettere che numeri
- Deve contenere almeno un simbolo
