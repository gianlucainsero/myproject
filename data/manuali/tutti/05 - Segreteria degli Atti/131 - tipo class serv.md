# Classificazioni/Servizi

## Accesso

Si accede a **Classificazioni/Servizi** attraverso il menù:

**Gestione Documentale → Archivi → Classificazioni/Servizi**

## Schermata principale

Dalla schermata principale è possibile:

- Creare un nuovo record tramite il pulsante **"Nuovo"**
- Impostare un filtro di ricerca

### Filtri di ricerca

I filtri disponibili nella schermata di ricerca sono:

| Campo | Descrizione |
|-------|-------------|
| **Codice** | Codice della classificazione |
| **Classificazione** | Nome della classificazione |
| **Solo Annullati** | Checkbox per filtrare solo i record annullati |

- Impostando più filtri di ricerca contemporaneamente è possibile operare **ricerche complesse**.
- Una volta completata l'impostazione dei filtri di ricerca, basterà cliccare su **"Elenca"** per ottenere un elenco dei record filtrati.
- Cliccando sul pulsante **"Elenca"**, senza aver impostato alcun filtro, il programma proporrà tutti i record presenti nel sistema.

## Scheda record

[Schermata di dettaglio record con i seguenti campi:]

| Campo | Descrizione |
|-------|-------------|
| **Codice*** | Codice identificativo (campo obbligatorio) |
| **Sigla** | Sigla associata |
| **Classificazione** | Nome della classificazione/servizio |
| **Data annullamento** | Data di annullamento del record |
| **Uff. Assegnato** | Ufficio assegnato (con pulsante di ricerca) |

### Pulsanti operativi

| Pulsante | Funzione |
|----------|----------|
| **F6-Aggiorna** | Salva/aggiorna il record |
| **F7-Cancella** | Elimina il record |
| **F6-Ambra Ricerca** | Torna alla schermata di ricerca |
