# Richiesta certificati penali per nominativo

Si richiede compilando una domanda in carta libera indirizzata a qualsiasi ufficio del Casellario presso le Procure della Repubblica.

## Percorso di navigazione

Il percorso da seguire è:

**Servizi demografici ⇒ Anagrafe ⇒ Estrazioni ⇒ Richiesta certificati penali per nominativo**

[Schermata del menu di navigazione: dal menu principale si seleziona "150. Servizi Demografici" → "10. Anagrafe" → "50. Estrazioni" → "30. Richiesta Certificati Penali per Nominativo"]

## Inserimento dei nominativi

Entrando all'interno, bisognerà inserire i nominativi dei soggetti per i quali si deve richiedere il certificato penale.

[Schermata con i pulsanti "F2 Aggiungi Nominativo" e "Crea File"]

## Generazione del file

Una volta inseriti i vari soggetti, attraverso l'apposito pulsante **"Crea file"** verrà generato il file da inviare alla Procura per poter avere i penali.

[Schermata del pulsante "Crea File" evidenziato]

## Esempio di file generato

Il file generato è un PDF (es. `RichiestaCertificatiPenali_06-12-2023_16_58_10_863400.pdf`) contenente un documento con intestazione:

06-12-2023
