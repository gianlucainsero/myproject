# Stampa Code Liste Sezionali

Tale programma permette di ri-stampare le code delle liste sezionali relative ad una determinata revisione.

## Percorso di navigazione

**Servizi Demografici ⇒ Elettorale ⇒ Revisione Storiche ⇒ Stampa Code Liste Sezionali**

[Menu a tendina: Servizi Demografici → Elettorale → Revisione Storiche → Stampa Code Liste Sezionali]

## Campi da valorizzare

Entrando all'interno, i campi da valorizzare saranno i seguenti:

1. **Tipo Lista Elettorale**
2. **Verbale** ⇒ Il campo del verbale deve essere **SEMPRE** valorizzato, in quanto senza il programma non effettuerà alcuna stampa;
3. **Codice testo** ⇒ Il codice testo da utilizzare è il seguente:
   - Codice: `cwl_ListeSezionali`
   - Descrizione: `Liste Sezionali`

   [Dropdown "Codice testo" con opzioni: Verbale Ricompilazione Liste Sezionali, Liste Sezionali digitali (si salto Pagina x Revisioni), Liste Sezionali digitali, **Liste Sezionali** (selezionato), Estratto Liste Sezionali per i Seggi da appendere al Muro NOVI DI MC]

4. **Seleziona** ⇒ In questo campo bisognerà indicare se effettuare la stampa delle code per gli iscrivendi, cambi di sezione o iscrivendi + cambi di sezione;

   Opzioni disponibili nel menu a tendina:
   - Tutti
   - Iscrivendi
   - Cancellandi
   - Cambi Sezione
   - Iscrivendi + Cambi Sezione

5. **Sesso**

## Conferma della stampa

Una volta compilati i vari campi, e controllato la correttezza del timbro finale, premere il bottone **"Conferma"** sulla destra così da procedere alla stampa.

[Modulo di stampa con campi: Verbale (numero, data, progressivo), Codice Testo, Seleziona, Sesso, Sezione elettorale da/a, Num. lista sez. da/a, Timbro finale. Pulsante "Conferma" evidenziato sulla destra.]

> ⚠️ Accertati che i dati del verbale e tutto il timbro siano corretti prima di confermare. In fase di stampa la scritta `@elettori@` verrà sostituita con il numero degli elettori.

> **NB:** viene creato un file per ogni sezione.
