# Gestione File 3D XML Ricevuti

## Percorso di accesso

Il percorso da seguire è:

**Servizi demografici** ⇒ **Elettorale** ⇒ **Manutenzione** ⇒ **3D XML e Certificati penali** ⇒ **Gestione file 3D XML ricevuti**

[Schermata del menu di navigazione: Servizi demografici → Elettorale → Manutenzione → 3D XML e Certificati penali → Gestione file 3D XML ricevuti]

## Descrizione della funzionalità

Permette di gestire i modelli 3D appena importati.

## Schermata principale

Aprendo la schermata, comparirà la lista dei file 3D XML ricevuti.

[Schermata "Gestione Modelli 3D XML" con tabella "3D non riconosciuti" contenente le colonne: Status, Comune di provenienza, Cognome, Nome, Codice fiscale, Data nascita, Luogo nascita, Note, Utente mod., Data mod. A destra sono presenti i pulsanti: Archivia, Riconosci soggetto, Visualizza XML, Altra Ricerca]

### Colonna "Status"

Nella prima colonna, su **"Status"** viene riportato un punto interrogativo (❓) che sta ad indicare quei 3D XML nei quali **non è stato riconosciuto il soggetto**.

[Tooltip "SOGGETTO SCONSOCIUTO" visualizzato al passaggio del mouse sull'icona del punto interrogativo]

## Riconoscimento del soggetto

In questi casi, per riconoscere il soggetto è stato posto un pulsante apposito che si trova a destra: **"Riconosci soggetto"**.

Grazie a questo pulsante il programma effettuerà una ricerca all'interno dell'archivio unico dei soggetti in modo tale da poter collegare il soggetto al file 3D XML.

## Visualizzazione del file XML

È possibile visualizzare il file XML attraverso il pulsante **"Visualizza XML"**.

## Archiviazione dei file

Inoltre è possibile effettuare l'archiviazione dei file attraverso l'apposito pulsante **"Archivia"**.

## Pulsanti disponibili

| Pulsante | Funzione |
|----------|----------|
| **Archivia** | Effettua l'archiviazione del file selezionato |
| **Riconosci soggetto** | Esegue una ricerca nell'archivio unico dei soggetti per collegare il soggetto al file 3D XML |
| **Visualizza XML** | Permette di visualizzare il contenuto del file XML |
| **Altra Ricerca** | Consente di effettuare una ricerca aggiuntiva |
