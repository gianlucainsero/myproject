# Importazione Certificati Penali

## Percorso di navigazione

Il percorso da seguire è:

**Servizi demografici ⇒ Elettorale ⇒ Manutenzione ⇒ 3D XML e Certificati penali ⇒ Importazione certificati penali**

[Schermata del menu a cascata del software: Servizi Demografici → Elettorale → Manutenzione → 3D XML e Certificati Penali → Importazione Certificati Penali]

## Procedura di importazione

### 1. Scompattamento del file

Per la ricezione dei certificati penali bisogna innanzitutto scompattare il file **.zip** ricevuto dal **tribunale** attraverso la password che si trova all'interno del file **key.pdf**.

### 2. Caricamento dei file

Una volta scompattata la cartella, caricare i file nei box:

- **riepilogo**
- **negativi**
- **positivi**

### 3. Scelta dei certificati

Scegliere i certificati di:

- **Iscrivendi in Revisione**: se la revisione semestrale è ancora aperta, in questo modo il programma andrà ad aggiungerli effettuando un controllo solo degli elettori in revisione.

- **Elettori**: se la revisione è già stata chiusa, in questo modo il programma li aggiungerà controllando nell'intero corpo elettorale.

### 4. Importazione

Una volta effettuata la scelta e caricati i file, procedere all'importazione tramite il bottone **→ Importa**.

> **NB:** I Certificati Penali precedentemente caricati non saranno importati.

[Schermata della finestra di importazione: tre campi di caricamento file (File riepilogo.zip, File negativi.zip, File positivi.zip), sezione "Certificati Penali di" con opzioni radio "Iscrivendi in Revisione" / "Elettori", e pulsante "Importa"]
