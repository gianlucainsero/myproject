# Web App ANPR

È possibile aprire la Web App ANPR utilizzando come credenziali il **codice fiscale** e la **password** di un Ufficiale d'Anagrafe censito sulla piattaforma di ANPR.

Per poter aprire la web app da questo punto di menù è necessario, inoltre, che sia installato un **certificato di postazione** sul PC.

Se, invece, si vuole accedere all'applicativo Ministeriale utilizzando la **smart card ANPR** occorre accedere dal seguente link:

[https://dp.anpr.interno.it/com](https://dp.anpr.interno.it/com)
