# Gestione Albo Presidenti di Seggio

Permette la modifica dei dati che sono rilevanti per la scelta del Presidente di seggio.

## Ricerca dei soggetti

La videata si apre con una maschera di ricerca dalla quale è possibile estrarre soggetti singoli o più soggetti in elenco.

**Campi di ricerca disponibili:**

- Cognome
- Nome
- Sesso (menu a tendina "Seleziona")
- Matricola

Per effettuare la ricerca, selezionare **F4/Elenca**.

[Schermata: maschera di ricerca con campi Cognome, Nome, Sesso e Matricola, con barra di navigazione "PALC1 Home", "Stampa Albo", "Gestione Albo"]

## Modifica dei dati

Dall'elenco è possibile, selezionando la **matitina**, modificare le informazioni rilevanti per poi cliccare su **Aggiorna**.

[Schermata: maschera di modifica del soggetto con i seguenti campi e sezioni:]

### Dati anagrafici e di iscrizione

| Campo | Descrizione |
|-------|-------------|
| Nome | Nome del soggetto |
| Sesso | Sesso del soggetto |
| Nato il | Data di nascita (gg / mm / aaaa) |
| Tipo lista | Tipo di lista |
| Stato | Stato del soggetto |
| Sezione | Numero di sezione |
| Num. Lista Sezionale | Numero nella lista sezionale |
| Fascicolo | Riferimento al fascicolo |
| Tessera | Numero di tessera |
| Matricola | Numero di matricola |

### Sezione: Iscrizione

| Campo | Descrizione |
|-------|-------------|
| Data richiesta | Data della richiesta di iscrizione |
| Numero verbale | Numero del verbale di iscrizione |
| Data verbale | Data del verbale (es. 01/01/2002) |

### Sezione: Requisiti

- ☐ Gradimento
- ☐ Ha svolto incarichi
- ☐ Ha capacità organizzative

### Sezione: Cancellazione

| Campo | Descrizione |
|-------|-------------|
| Causale | Menu a tendina "Seleziona una causale" |
| Numero verbale | Numero del verbale di cancellazione |
| Data verbale | Data del verbale di cancellazione |
