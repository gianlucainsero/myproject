# Gestione Tessere per Numero

Molto simile a **Gestione Tessere per Nominativo**, solo che la ricerca è puntuale e viene effettuata per numero tessera, di conseguenza l'interrogazione ha una schermata che si presenta così:

[Schermata di interrogazione "Gestione Tessere Elettorali": campo di input "Numero tessera :" con valore predefinito 0, all'interno della sezione "Gestione Tessere Elettorali" del modulo "Gestione Tessere Elettorali" (tab PALC1 Home > Gestione Tessere Elettorali), per l'Ente di Demo]

L'elenco che risulta dalla ricerca è il medesimo dell'altro programma, di conseguenza anche la schermata di modifica:

[Schermata di modifica tessera elettorale con i seguenti campi:
- **Dati anagrafici:** Nome, Sesso (M), Nato il (1/8/1990), Tipo lista (1), Stato, Sezione (9), Num. Lista Sezione (505), Fascicolo (33099), Tessera (135542319), Matricola (13342)
- **Dati tessera:** Numero tessera (135542319), Matricola, Tipo tess. elettorale (— Seleziona un valore —), Duplicato (checkbox), Codice Carico, Numero tessera
- **Annullamento tessera:** Stato (1 - attiva), Data, Motivo
- **Variazioni tessera:** tabella con colonne: Dt. var. tessera, Sez., Num. lista sez., Id indirizzo, Indirizzo (es. VIA MARCO POLO n. 14), Id interno, Interno, Data notifica (es. 16/04/2015)]
