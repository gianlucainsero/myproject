# Collegamento Matricole con ID ANPR

Nel caso in cui mentre si lavora in ANPR dovesse comparire un messaggio del genere:

> **Errore completamento pratica**
>
> ⚠️ 0 ANPR - Identificativo soggetto attribuito dal comune 170251 non presente o scheda archiviata

Controllare il corretto allineamento delle matricole tra Cityware ed ANPR.

## Percorso di navigazione

Dal menu principale, seguire il percorso:

**MENU** → **150. Servizi Demografici** → **10. Anagrafe** → **70. ANPR - Funzioni di Servizio** → **30. Corrispondenza ID ANPR e Cityware**

## Procedura di collegamento soggetto

1. **Selezionare il soggetto con la lente** (icona di ricerca 🔍) nel campo **Matricola**.

   [Screenshot: Schermata "Estensione ANPR DAN_ANAGRA e DAN_FAMI" con sezione "Identificativi soggetto" contenente i campi Matricola e ID ANPR, ciascuno con pulsante di ricerca (lente). Sezione "Audit Soggetto" con campi "Ultima modifica" e "Effettuata da". Pulsanti "Aggiorna" e "Annulla".]

2. Se il soggetto è **già collegato**, il programma non permette di fare altro.

3. Altrimenti, una volta ricercata la matricola:
   - Cercare l'**ID ANPR** corrispondente sempre con la lente (icona di ricerca) nel campo **ID ANPR**
   - Premere il tasto **Aggiorna**

## Procedura di collegamento famiglia

Dopo aver collegato i due ID è possibile reinoltrare le variazioni che avevano dato errore.

Lo stesso meccanismo può essere usato per il collegamento della famiglia:

1. Nel campo **CW FAMIGLIA**, selezionare la famiglia con la lente (icona di ricerca 🔍).
2. Nel campo **ANPR FAMIGLIA ID**, cercare l'ID corrispondente con la lente.
3. Premere il tasto **Aggiorna**.
