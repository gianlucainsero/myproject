# Manuale Invio Variazioni per HERA

## Percorso di navigazione

Andare al punto di menu: **Servizi Demografici - Anagrafe - Estrazioni - Lettore Estrazioni**

## File da controllare e scaricare

La finestra presenterà alcuni file, quelli da controllare e scaricare sono:

- **GLOBALEHERA.txt**
- **VARIAZIONIHERA.txt**

[Schermata della finestra "Lettore Estrazioni" con la cartella HERA (ESTRAZ_HERA) contenente i file GLOBALEHERA., GLOBALEHERA.TXT e VARIAZIONIHERA.TXT con relative dimensioni e date ultima modifica]

## Descrizione dei file

Il file **GLOBALEHERA.txt** contiene una foto della popolazione residente e viene generato automaticamente il **1° gennaio** e il **1° luglio** di ogni anno.

Il file **VARIAZIONIHERA.txt** contiene le variazioni mensili e viene generato automaticamente **ogni 1° del mese**, naturalmente contiene le variazioni del mese precedente.

## Verifica della data ultima modifica

Prima di scaricare i file, accertarsi che la **data ultima modifica** porti la data del **1° del mese corrente**.

**Esempio:**

- Se si va a scaricare il file il giorno **5 marzo 2026**, assicurarsi che data ultima modifica sia **01-03-2026**
- Se si va a scaricare il file il giorno **20 aprile 2026**, assicurarsi che data ultima modifica sia **01-04-2026**

## Procedura di download

Una volta verificata la data, con esito positivo, scaricare il file tramite l'iconcina a sinistra (icona di download).

[Schermata della finestra Lettore Estrazioni con l'icona di download evidenziata a sinistra dei file GLOBALEHERA.TXT e VARIAZIONIHERA.TXT]

## Anteprima e invio del file

Il file si aprirà prima in anteprima dove sarà poi possibile scegliere se:

- **Scaricarlo** nella cartella dei download, tramite il bottone **'Scarica'**, per poi inviarlo tramite mezzo desiderato
- **Inviarlo direttamente ad Hera** tramite il bottone **'Protocolla'**

[Schermata della finestra "Visualizzazione Documenti" con i pulsanti "Protocolla", "Scarica" e "Salva in file-box" in alto, e l'anteprima del contenuto del file VARIAZIONIHERA.TXT con i record anagrafici]

## Frequenza di invio

> **NOTA BENE!**
> Le variazioni vanno inviate **tutti i mesi**, mentre il globale va inviato il **1° gennaio** ed il **1° luglio** di ogni anno.
