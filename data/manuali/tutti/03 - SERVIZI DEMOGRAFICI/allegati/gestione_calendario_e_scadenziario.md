# INSERIRE E UTILIZZARE IL CALENDARIO CON LE SCADENZE ANAGRAFICHE

Questa guida vi spiegherà come inserire il calendario e caricare le scadenze dei Servizi Demografici.

Il calendario, oltre alle scadenze fornite, può essere personalizzato con l'aggiunta dei propri appuntamenti.

---

## 1) Attivare il calendario

Se non vedete il calendario nella Home, quindi nella pagina principale al momento dell'accesso, è il momento allora di attivarlo:

### a) Accedere alla Gestione Portlet

Spostate il cursore in alto a destra sulla sezione **"Impostazione ed Utilità"** [1] e selezionare **Gestione Portlet** [2].

[Immagine: Barra superiore dell'applicativo con la sezione "Impostazione ed Utilità" evidenziata e il pulsante "Gestione Portlet" selezionato nel Pannello di Controllo]

### b) Aggiungere la Gestione Calendario

Vi si aprirà una piccola videata con varie opzioni, cercate la **"Gestione Calendario"** e con il tasto **+ verde** a destra aggiungetela.

[Immagine: Finestra "Gestione desktop utente" con elenco portlet e colonna "Portlet" con icone +/− verdi e rosse. La voce "Gestione Calendario" è evidenziata con il pulsante + verde]

Vi chiederà poi in che modalità aggiungere il calendario:

- **Portlet**: lo aggiunge sulla home come uno specchietto
- **App**: crea un'altra pagina di fianco alla Home

[Immagine: Dialog "Aggiungi Portlet" con messaggio "Selezionare il metodo di apertura del model" e pulsanti "App" e "Portlet"]

---

## 2) Configurare il calendario

Una volta scelto come usare il calendario seguite questi passaggi per configurarlo:

### a) Aprire le impostazioni

Selezionate il calendario e cliccate sull'**ingranaggio** (icona impostazioni).

[Immagine: Vista calendario con barra strumenti in alto contenente icone "Oggi", "Nuovo", ingranaggio (evidenziato in rosso) e chiave inglese]

### b) Selezionare il calendario

Selezionate con un click dove c'è il riquadro rosso, comparirà una finestra.

[Immagine: Finestra "Impostazioni Calendario" con tabella "Seleziona calendari" contenente colonne: Selez., Nome calendario, Proprietario, Perm. gruppo, Perm. altri, Colore, Disab. La riga "Calendario Demografico" è selezionata con checkbox]

### c) Confermare e riavviare

Uscire e rientrare nell'applicativo (Solo al **PRIMO** accesso occorrerà dare tempo all'applicativo di caricare tutti i riferimenti).

Da questo momento in poi le nuove scadenze saranno attive nel calendario.

---

## 3) Aggiungere eventi personalizzati

È possibile aggiungere eventi personalizzati nel calendario in modo da visualizzarli. Per farlo, selezionate la **chiave inglese**:

[Immagine: Barra strumenti del calendario con icona chiave inglese evidenziata in rosso. Menu a tendina "Funzioni Disponibili" con opzioni: Crea Eventi (icona + verde), Duplica Eventi (icona freccia), Elimina Eventi (icona X rossa)]

E successivamente compilate la videata. In **rosso** i campi obbligatori. Potete gestire gli orari, la durata, dare un titolo:

[Immagine: Finestra "Crea Eventi" con i seguenti campi:]

| Campo | Obbligatorio | Descrizione |
|-------|:---:|-------------|
| Calendario | ✓ | Selezione del calendario di destinazione |
| Titolo | ✓ | Nome dell'evento |
| Dalla data | ✓ | Data di inizio |
| Alla data | ✓ | Data di fine |
| Ora inizio | ✓ | Ora di inizio |
| Ora fine | ✓ | Ora di fine |
| Rispetta l'ora fine | | Checkbox |
| Esclusione 1° giorno | | Campo data |
| Esclusione 2° giorno | | Campo data |
| Ripetizioni | ✓ | Numero di ripetizioni |
| Durata (min) | ✓ | Durata in minuti |
| Pausa (min) | | Pausa tra ripetizioni |
| Lun / Mar / Mer / Gio / Ven / Sab | | Giorni della settimana |

Pulsante di conferma: **F5-Conferma**
