# Controllo Albo Presidenti di Seggio per Creazione proposte di cancellazione

Questo programma effettua un'estrazione per la creazione delle proposte di cancellazione, che sono riassunte in un file Excel. Il flag **stampa elenco** crea il file Excel e il flag **archivio** produce un archivio dati: queste due spunte non sono obbligatorie, quindi potete anche compiere l'estrazione senza poi stampare il file Excel o produrre un archivio di dati.

Selezionare **conferma** per concludere.

## Interfaccia del programma

[Schermata del programma "Controllo Albo per Creazione Proposte di Cancellazione" con sezione "Tipo Elaborazione" contenente due checkbox: "Stampa Elenco" (selezionata) e "Creazione Archivio" (selezionata). L'intestazione mostra "Ente di Demo" e la scheda attiva "PALC1 Home".]

## Opzioni disponibili

| Opzione | Descrizione | Obbligatoria |
|---------|-------------|--------------|
| **Stampa Elenco** | Crea il file Excel con le proposte di cancellazione | No |
| **Creazione Archivio** | Produce un archivio dati | No |

## Procedura

1. Accedere alla funzione **Controllo Albo per Creazione Proposte di Cancellazione** dalla schermata principale (scheda *PALC1 Home*).
2. Nella sezione **Tipo Elaborazione**, selezionare le opzioni desiderate:
   - Spuntare **Stampa Elenco** per generare il file Excel riepilogativo.
   - Spuntare **Creazione Archivio** per produrre l'archivio dati.
   - È possibile eseguire l'estrazione anche senza attivare nessuno dei due flag.
3. Selezionare **conferma** per concludere l'elaborazione.
