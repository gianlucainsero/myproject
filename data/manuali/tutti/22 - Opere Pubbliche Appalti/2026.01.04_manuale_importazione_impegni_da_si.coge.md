# Importazione Impegni da Foglio Excel

## Percorso di Accesso

Per poter accedere alla funzione è necessario seguire il percorso:

**90. Lavori pubblici → 30. Opere Pubbliche → 60. Utilità → 10. Importa Impegni da SI.COGE**

[Diagramma: Menu a cascata del software PALCI che mostra il percorso di navigazione: 90. Lavori Pubblici → 30. Opere Pubbliche → 60. Utilità → 10. Importa Impegni da SI.COGE]

## Parametri di Import

Il programma apre una maschera che evidenzia i parametri di import, i quali sono stati impostati per default ma sono parametrizzabili e modificabili dall'utente in base alla necessità.

**Esempio:** è impostato per default « inserisci CUP se inesistente » ma l'utente può deselezionare tale flag e salvare l'impostazione per i successivi import attraverso il bottone **« Salva parametri »**.

È possibile consultare la struttura del file Excel da rispettare per una corretta importazione cliccando sul bottone **« Struttura XLSX ammessa »**.

[Diagramma: Maschera "Import Impegni da Foglio Excel" con i parametri di import: Inserisci CUP se inesistente, Inserisci CUP se inesistente per CUP, Inserisci CIG se inesistente, Inserisci CIG se inesistente per CIG, Località di default, Effettua Variazione della Ragione Sociale, Codice Pagamento di Default (CASSA), Genere di Impegno, Classificazione di Default, Tipo Atto di Default (DECRETO PROVVEDIMENTALE), Codice Statistico per Oneri, Natura della Nota, Esclusi da MANCA OPERA, Esclusi da CAPITOLI NON IN BILANCIO. Pulsanti: Struttura XLSX ammessa, Salva Parametri, Seleziona File XLSX da Importare]

## Selezione del File

Cliccare su **"Seleziona File XLSX da Importare"** e fare doppio click sul file degli impegni.

[Diagramma: Finestra di dialogo "Apri" di Windows Explorer con percorso "Risultati ricerca in Download > Download > Immagini", file selezionato "IMPEGNI 2025 CAP 7261.xls" (25 KB, Foglio di lavoro di Microsoft Excel), pulsante "Apri" evidenziato]

## Riepilogo dell'Importazione

Al termine dell'importazione del file il programma produce un riepilogo sulle operazioni che andrà a fare. **Si precisa che ancora non è stato importato nessun impegno.**

[Diagramma: Finestra "Riepilogo dei Dati Elaborati - Righe Contenute nel File Excel 67" con tabella riepilogativa:

| | Inseribile | Dati da XLSX | Da Inserire | Già Inseriti | Esclusi | Errori |
|---|---|---|---|---|---|---|
| Cap | Inseribile | 0 | 0 | 0 | 0 | 0 |
| Cdg | Inseribile | 41 | 0 | 25 | 11 | 0 |
| Soggetti | Inseribile | 60 | 0 | 36 | 5 | 0 |
| Impegni | Inseribile | 67 | 1 | 22 | 44 | 0 |

Capitoli Generati nel File XLSX: 02/007301 ANNO 06 - CIG: 7261 - 1)

Codice Statistico OP0000 non trovato nel File XLSX e sugli Archivi per cui 44 impegni su di essi saranno Esclusi e quindi non verranno importati.]

## Impegni Validi

Gli impegni importabili sono quelli elencati nella rispettiva tab **"Impegni Validi"**. A tal punto occorre effettuare delle precisazioni:

- Se un impegno è **presente**, il programma procede aggiornando solamente il **« pagato su impegno »** ;
- Se un impegno **non è presente**, il programma lo inserisce ex novo.

[Diagramma: Tab "Impegni Validi (23)" con colonne: Riga XLSX, Anno Proven, Num.Riga Impegno, Anno Impegno, Importo Impegno, Pagato su Impegno, STATO Impegno, Competenza Residui, Capitolo, Disponibilità Capitolo, Cod Statistico OP0000, CUP, Cig, STATO Cup. Esempi di righe con stato "Da Inserire" o "Esistente" e indicatori verdi/rossi]

## Impegni Esclusi

Gli impegni scartati vengono elencati nella tab **"Impegni Esclusi"**. Gli errori che hanno prodotto lo scarto sono evidenziati in **rosso**. A tal punto resta all'operatore verificare che gli impegni esclusi siano corretti o altrimenti apportare le modifiche necessarie per l'importazione.

[Diagramma: Tab "Impegni Esclusi (44)" con colonne: Riga XLSX, Anno Proven, Num.Riga Impegno, Anno Impegno, Importo Impegno, Pagato su Impegno, STATO Impegno, Competenza Residui, Capitolo, Disponibilità Capitolo, Cod Statistico OP0000, CUP, Cig, STATO Cup. Errori evidenziati in rosso nella colonna "Cod Statistico OP0000" con testo "Manca su XLSX"]

## Esecuzione dell'Importazione

Una volta effettuate le verifiche si può procedere con l'importazione: è possibile lanciare prima una **simulazione (1)** per poi procedere con la **creazione (2)**.

[Diagramma: Pannello a destra con due pulsanti sovrapposti: (1) "Simulazione Import" e (2) "Crea Impegni"]

## Visualizzazione del Contenuto del File

Il bottone **"Visualizza il contenuto del File XLSX da importare"** permette di visualizzare da programma il file Excel scelto per l'importazione.

[Diagramma: Pulsante "Visualizza il contenuto del File XLSX da importare" in alto a destra nella schermata. Sotto, tabella "Contenuto del file XLSX" con colonne A-N mostranti i dati grezzi del foglio Excel (numeri, date, codici)]
