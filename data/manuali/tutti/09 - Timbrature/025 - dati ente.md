# Anagrafica Dati Ente

Questa anagrafica è utilizzata per la gestione dei dati dell'ente.

Alla sua apertura l'applicativo si presenterà come segue:

[Schermata dell'applicativo "Anagrafica Dati Ente" con i seguenti pannelli: Dati Generali (Tipo Stampa, Righe per Pagina, Tipo Fine, Cod. Compensaz., Modello di Stampa, Tipo calcolo max/minimo, Voce per Buoni P., Visualizzazione D.L.G., Rep. Mese Precedente, Tipo calcolo accumulo, Minuti per attivare buono pasto), Dati per Giustificativi (Tipologia Giust., Codice Prof. Gen., PROFILO FISSO orario), Indirizzo Porte per scarico diretto orologi (Orologio locale, Velocità di trasmiss., Orologi remoti, Velocità di trasmiss. Attesa, modem/rilevatore di trasmiss. Attesa modem), Dati per Inail (Progressivo, Numero Autoriz., Cod, Codice Sede, Provincia Sede), Dati per Autorizzazioni Web (User Name Timbrat., Email), Legge Brunetta sulla Trasparenza (Anno da Consultare, Vs. per, Centro di costo, Voce per gg lav., Compensazioni Giornaliere)]

Questi dati sono dei **"parametri"** utilizzati dal software.

Al suo interno troviamo:

- **Dati Generali**: dati riguardanti la stampa
- **Dati per Giustificativi**: dati riguardanti i giustificativi
- **Indirizzo porte per scarico diretto orologi**: dati riguardanti gli orologi
- **Dati per Inail**: sono i dati riguardanti la stampa INAIL
- **Dati per Autorizzazioni Web**: dati riguardanti le autorizzazioni web (User Name Timbrat. ed Email)
- **Legge Brunetta sulla Trasparenza**: dati riguardanti la medesima legge
- **Altri Orologi**: dati riguardanti l'utilizzo di altri orologi
- **Ditta**: dati riguardanti il controllo ditte e la ditta di default per lo scarico
